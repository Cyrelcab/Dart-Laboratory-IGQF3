# Dart-Laboratory-Activity
Laboratory Activity 1. (CO1-CO2 Laboratory)

Students must create a Dart program that solves their assigned problem.
(https://dart.dev/docs)

Important Rules
1. Each student must work on their own branch.
2. Students must not directly modify the main branch.
3. Each student must have a different programming problem.
4. Students must test their program before creating a Pull Request.
5. Pull Requests must be approved before merging.

Github Workflow
Fork
 ↓

 ↓

 ↓

Problems:
Group 1.
* Ask the user to enter the prices of 5 products. Then calculate the total, and if the total >= 1,000pesos then give a 10% discount.

Group 2.
* Ask the user to input a positive integer. Then calculate the factorial.

Group 3.
* Ask the user to input 5 numbers. Then count the total even numbers and total odd numbers.

Group 4
* Ask the user to enter 5 numbers.
    For each number, determine whether it is divisible by: 2, 3, 5

Group 5.
* Ask the user for the number of rows.

Display:

1
12
123
1234
12345

Group 6
* Ask for the number of rows.

Display:

12345
1234

1

Group 7.
* Ask the user to enter 5 numbers. Then identify which number is the smallest.

Group 8
* Ask the user to enter 5 numbers. Then identify which number is the largest.
